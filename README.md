Day 2 Project 2 - Helpdesk Ticketing System



Description

A console-based mini Helpdesk Ticketing System built using Java OOP concepts.



Concepts Used

\- Encapsulation (private fields + public getters)

\- Parameterized Constructors

\- Object References between classes



Classes

\- User.java - Stores user details

\- Ticket.java - Stores ticket details with assigned user

\- App.java - Main class to run the application



Tech Stack

\- Java 17

\- Maven
